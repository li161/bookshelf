# BOOKVERSE — The Infinite Library

An immersive 3D digital library built with Vue 3, TypeScript, Three.js, GSAP and Pinia.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run typecheck
npm run build
```

## GitHub Pages
The project is configured for deployment at `https://li161.github.io/bookshelf/`. The workflow in `.github/workflows/deploy.yml` builds and publishes the `dist` directory on pushes to `main`.

## Experience
- Procedural 3D library architecture and 12 distinct book meshes
- Raycaster selection, orbit exploration and camera focus
- Book opening sequence with animated page leaves and three unique world environments
- Time-room lighting presets, knowledge galaxy, secret archive and personal shelf
- Responsive overlay UI and reduced-quality rendering on constrained devices
